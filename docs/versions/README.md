# Version Definitions

This directory contains concrete Pantheon version definitions created from `docs/development/version-template.md`.

A version definition states the release outcome, product proof, supported envelope, deliberate deferrals, release gate, and release evidence for one release boundary. It does not replace the Engineering Mission Issues grouped by the corresponding GitHub Milestone.

Version-planning semantics live in `docs/development/versions.md`; files here are instances of that contract.
